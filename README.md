# Identity Data Retrieval System

## 🧩 Overview
This C# Windows Forms application retrieves personal details from a Sri Lankan National Identity Card (NIC) number.  
It determines **gender**, **birth year**, and **birth date (month and day)** based on either the old 10-character or new 12-character NIC format.

## ⚙️ Features
- Validate NIC format (10 or 12 digits)
- Extract and display birth year
- Determine gender (Male/Female)
- Calculate and display birth month and day

## 🖥️ Interface
The form includes:
- TextBox: Input NIC number  
- Button: “Generate”  
- Labels: Display Gender, Year, Month, and Date
